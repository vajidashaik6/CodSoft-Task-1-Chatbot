# 🤖 CampusBuddu - Smart Student Rule-Based Chatbot

A modern and interactive rule-based chatbot designed to assist college students with common academic and campus-related queries.

This project was developed as **CodSoft Task 1** using HTML, CSS, and JavaScript.

## 📌 Project Overview

CampusBuddu is a student-friendly chatbot that provides quick responses to common college-related questions.

The chatbot has a clean and modern interface and uses predefined rules to understand user queries and generate suitable responses.

## ✨ Features

- 💬 Interactive chatbot interface
- 🎓 College and academic-related responses
- ⚡ Instant responses
- 🧠 Rule-based response system
- 🎨 Modern and responsive UI
- 📱 User-friendly design
- 🔄 Clear chat functionality
- ⌨️ Easy message input and interaction

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
